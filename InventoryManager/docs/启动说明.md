# 库存管理服务启动说明

## 🚀 快速开始

### 方式1：使用启动脚本（推荐）

1. **给启动脚本执行权限**
```bash
chmod +x start.sh
```

2. **运行启动脚本**
```bash
./start.sh
```

启动脚本会自动：
- 检查Python版本
- 安装依赖
- 创建环境配置文件
- 检查数据库连接
- 初始化数据库
- 填充示例数据
- 启动服务

### 方式2：手动启动

1. **安装依赖**
```bash
pip install -r requirements.txt
```

2. **配置环境变量**
```bash
cp .env.example .env
# 编辑.env文件，设置数据库连接信息
```

3. **初始化数据库**
```bash
python -m flask init-db
```

4. **填充示例数据**
```bash
python -m flask seed-data
```

5. **启动服务**
```bash
python app.py
```

## 🐳 Docker部署

### 使用Docker Compose（推荐）

1. **启动所有服务**
```bash

```

2. **查看服务状态**
```bash
docker-compose ps
```

3. **查看日志**
```bash
docker-compose logs -f app
```

4. **停止服务**
```bash

```

### 手动构建Docker镜像

1. **构建镜像**
```bash

```

2. **运行容器**
```bash
docker run -d \
  --name inventory-app \
  -p 5000:5000 \
  -e DATABASE_URL=mysql+pymysql://user:pass@host:3306/db \
  inventory-management
```

## 🗄️ 数据库配置

### MySQL配置

1. **创建数据库**
```sql
CREATE DATABASE inventory_management CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

2. **创建用户**
```sql
CREATE USER 'inventory_user'@'%' IDENTIFIED BY 'inventory_pass';
GRANT ALL PRIVILEGES ON inventory_management.* TO 'inventory_user'@'%';
FLUSH PRIVILEGES;
```

3. **环境变量配置**
```bash
DATABASE_URL=mysql+pymysql://inventory_user:inventory_pass@localhost:3306/inventory_management
```

### 数据库初始化

```bash
# 创建所有表

# 填充示例数据
```

## 🔍 故障排除

### 常见问题

1. **数据库连接失败**
   - 检查MySQL服务是否运行
   - 验证数据库连接字符串
   - 确认用户权限

2. **端口被占用**
   - 检查5000端口是否被占用
   - 使用 `lsof -i :5000` 查看占用进程
   - 修改端口或停止占用进程

3. **依赖安装失败**
   - 升级pip: `pip install --upgrade pip`
   - 使用虚拟环境
   - 检查Python版本（需要3.8+）

4. **权限问题**
   - 确保有写入logs和uploads目录的权限
   - 检查文件权限设置

### 日志查看

```bash
# 应用日志
tail -f logs/inventory_service.log

# 访问日志
tail -f logs/access.log

# Docker日志
docker-compose logs -f app
```

## 📊 性能优化

### 生产环境配置

1. **使用Gunicorn**
```bash

```

2. **启用缓存**
```bash

# 配置缓存
CACHE_TYPE=redis
REDIS_URL=redis://localhost:6379/0
```

3. **数据库连接池**
```bash
# 在config.py中配置
SQLALCHEMY_ENGINE_OPTIONS = {
    'pool_size': 20,
    'pool_recycle': 3600,
    'pool_pre_ping': True
}
```

### 监控和日志

1. **日志轮转**
```bash

/var/log/inventory_service/*.log {
    daily
    rotate 30
    compress
    delaycompress
    missingok
    notifempty
```

