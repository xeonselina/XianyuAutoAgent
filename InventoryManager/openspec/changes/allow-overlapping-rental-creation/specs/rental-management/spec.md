## MODIFIED Requirements

### Requirement: 新建租赁时严格验证库存

新建租赁 MUST 使用所选仓库内处于正常可出租生命周期的主设备和库存附件。主设备和库存附件与其他租赁的有效占用时间重叠时，系统 MUST 允许保存，并保留两条独立租赁记录。主设备与附件不能在同一次预约中重复选择同一库存设备；不属于所选仓库或生命周期不可出租的设备仍 MUST 被拒绝。

#### Scenario: 主设备或附件已有重叠档期
- **WHEN** 操作员在 PC、移动端或创建 API 中选择与另一条活动租赁占用时间重叠的主设备或库存附件并提交有效新租赁
- **THEN** 创建接口返回 201，保存新主租赁和所选库存附件子租赁，原租赁不变；不得因重叠返回 `409 DEVICE_UNAVAILABLE`

#### Scenario: 设备不属于所选仓库
- **WHEN** 主设备或附件属于其他仓库
- **THEN** 系统返回仓库不匹配错误，且不创建租赁

#### Scenario: 设备已售出或停用
- **WHEN** 新建请求选择非正常可出租生命周期的设备
- **THEN** 系统拒绝该设备选择，不创建租赁

### Requirement: 按实际占用时间判断档期冲突

档期检查 MUST 优先使用寄出时间和收回时间；缺失时分别使用租赁开始日的起点和结束日的终点。`not_shipped`、`scheduled_for_shipping`、`shipped`、`returned` 状态占用档期，完成或取消的租赁不再占用档期。新建时该检查结果用于显示冲突及查找空闲设备，不阻止有效租赁写入。

#### Scenario: 物流时间延伸到另一租赁
- **WHEN** 两条租赁的起止日期不重叠，但寄出至收回的有效占用时间重叠
- **THEN** 冲突查询将该设备判定为占用，新建租赁仍可保存

#### Scenario: 旧记录缺少物流时间
- **WHEN** 一条活动租赁没有寄出或收回时间
- **THEN** 档期检查使用其租赁日期边界判断冲突

### Requirement: 同单多设备预约原子保存

同单录入的主设备 MUST 属于同一型号，且主设备和库存附件不能在同一次预约或已录同单记录中重复。多设备创建及补齐 MUST 在同一个事务中保存全部设备及其附件。与其他订单已有档期重叠不使同单创建或补齐失败。

#### Scenario: 同单创建两台设备
- **WHEN** 操作员为同一订单选择两台同型号主设备，其中一台与其他订单已有档期重叠
- **THEN** 系统一并创建对应主租赁和附件租赁，并关联同一预约

#### Scenario: 第二台设备校验失败
- **WHEN** 同单的任一设备或附件无效、生命周期不可出租或跨仓库
- **THEN** 整个创建请求失败，先前选中的设备也不会被部分保存

#### Scenario: 同单重复选择设备
- **WHEN** 两台设备选择同一库存 ID，或补齐时再次选择该单已录的库存 ID
- **THEN** 整个请求失败，不创建部分租赁

### Requirement: 新建设备清单与查找档期

PC 新建设备清单 MUST 限于所选型号，标出生命周期或档期状态；非正常生命周期设备不得选择。操作员可手动选设备或调用甘特图查找档期自动匹配。移动端设备列表 MUST 包含当前仓库、所选型号的可出租主设备，即使档期重叠，并按型号、名称自然排序。多设备选择 MUST 排除表单中已经占用的主设备和库存附件 ID。查找档期仍只返回空闲候选。

#### Scenario: 查找可用设备
- **WHEN** 操作员已填型号、租期和物流天数并点击“查找档期”
- **THEN** 表单从可用候选中选一台尚未被本次订单其他行选中的设备，并显示其名称

#### Scenario: 查找时改变条件
- **WHEN** 较早一次档期查询尚未返回，操作员已经修改型号或租期并发起新查询
- **THEN** 较早的结果不覆盖当前表单选择

#### Scenario: 无空闲候选时手动选择
- **WHEN** 所选型号全部设备在当前租期重叠，查找档期没有结果
- **THEN** PC 和移动端仍列出可出租设备，标记已知冲突并允许手动选择

## ADDED Requirements

### Requirement: 新建表单展示冲突但允许选择

PC 和移动端的新建表单 MUST 允许操作员选择同仓库、同型号且生命周期可出租的主设备，即使其档期与其他租赁重叠。库存附件与其他租赁重叠时也 MUST 可选择。已知冲突 MUST 以档期冲突提示展示；查找空闲档期的入口 MUST 继续优先返回无冲突设备。未确认的冲突查询不得被标作空闲。跨仓库、非正常生命周期和同单重复选择仍 MUST 被阻止。

#### Scenario: 手动选择冲突设备
- **WHEN** PC 或移动端操作员选择已被另一租赁占用的主设备或库存附件
- **THEN** 表单显示档期冲突提示但允许提交；服务端成功保存后显示创建成功

#### Scenario: 当前型号没有空闲设备
- **WHEN** 所选型号的设备都已有重叠档期
- **THEN** 操作员仍可从该仓库的可出租设备中手动选择并保存，查找空闲档期仍报告无空闲候选
