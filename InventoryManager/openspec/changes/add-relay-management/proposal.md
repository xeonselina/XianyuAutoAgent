# Change: 增加接力管理页

## Why

甘特图不适合集中识别和跟进物流区间重叠至少 2 天的客户间直接转寄。运营人员需要一个独立页面查看前后订单、管理沟通和寄出状态，并跟踪顺丰物流。

## What Changes

- 新增独立的接力管理记录，与现有永久接力绑定分离。
- 实时识别同设备相邻主 rental 中物流重叠至少 2 天的组合。
- 支持待处理、已通知、已同意、已寄出和已完成状态，并在已同意及之后同步永久绑定。
- 录入顺丰运单号，使用前单客户手机号后四位复用现有顺丰轨迹能力。
- 增加桌面端紧凑宽表和独立移动接力工作台。
- 当前后镜头组合不一致或后单附件更多时，两端显示配置差异告警。
- 默认筛选除已完成外的状态，并按前单应寄出日默认限定为 T-3 至 T+5。

## Impact

- Affected specs: `relay-management`
- Affected code: rental 接力模型与迁移、接力服务与 API、顺丰查询共享服务、PC Vue 路由/页面、移动 Vue 路由/页面
