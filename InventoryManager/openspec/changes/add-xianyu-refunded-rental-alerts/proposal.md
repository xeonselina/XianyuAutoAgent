# Change: 提醒退款/关闭订单仍保留档期

## Why
闲鱼订单已退款或关闭后，本地未处理档期仍可能进入发货流程。现有漏录提醒排除所有已录入订单，无法发现此问题。

## What Changes
- 按用户已确认的交互，复用甘特图漏录提醒条：默认收起、展开订单及各设备档期、手动确认删除、处理后即时更新。
- 按店铺及订单号核对平台真实状态，一单多设备正常履约时不提醒。
- 订单状态 23/24 提示清理；订单仍有效的退款/退货只提示核对，已发货先核对设备回收。
- 保存独立缓存，单笔查询失败保留旧提醒，不影响其他已核实订单。

## Impact
- Affected specs: xianyu-rental-alerts
- Affected code: 对账服务、提醒缓存及迁移、甘特图提醒及现有删除流程。
- 用户已在会话中确认交互并授权实现。测试禁止访问 `.env` 中的数据库，使用隔离 SQLite 与模拟闲鱼接口。
