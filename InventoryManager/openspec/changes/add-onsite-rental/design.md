## Context

当前快递表单固定按“物流天数 + 1”生成 `ship_out_time` / `ship_in_time`。部分档期与空闲查询只识别这两个非空字段，待归还只列结束日不晚于昨天的 `shipped` 租赁。因此现场单即使隐藏物流字段，也需要让按天占用和当天待归还进入这些查询。

## Decisions

### 数据与兼容

- 在租户业务库 `rentals` 增加非空 `fulfillment_mode`（`courier|onsite`，默认 `courier`）、可空 `onsite_note` 和 `onsite_returned_at`；历史行回填 `courier`，创建 API 未提供时也按 `courier` 处理。
- 主租赁及库存附件子租赁保存相同的履约方式和使用日期；详情、列表及甘特响应返回 `fulfillment_mode`。
- 现场单的 `ship_out_time` / `ship_in_time` 均为空。公共档期计算按模式选择边界：快递使用现有物流时间及缺失回退；现场使用 `[使用日 00:00, 次日 00:00)`。`onsite_returned_at` 由服务端在归还动作时记录，不要求用户选择时间。
- 现场记录的地址、物流时间、运单号及预约发货时间必须为空；若请求包含这些非空字段，服务端返回字段错误。现场记录可带闲鱼订单号，但不得带 `scheduled_for_shipping` 状态。
- 保存后 `fulfillment_mode` 不可编辑；旧客户端编辑现场单时，省略方式按记录的现有方式处理，不能重置为 `courier`。
- `RentalBooking` 的关联主租赁必须使用同一种方式；追加同单设备时以原 booking 方式校验。无闲鱼订单号的现场多设备请求继续使用现有请求标识保证幂等。

### 时间与状态

- 现场使用日 `start_date=end_date`。PC / 移动端新建现场单时，使用日期按 Asia/Shanghai 今天预填，用户可修改；切换方式或日期后清除旧空闲结果。创建、编辑和查档期都用整天占用区间。
- 现场操作对应 `not_shipped`（待交付）→ `shipped`（使用中）→ `returned`（已归还）→ `completed`（已完成），可取消未交付的现场单。交付 / 归还只更新当前租赁及附件，不触发快递或闲鱼动作。
- 归还动作由服务端写入 `onsite_returned_at`，同步主租赁与库存附件。若实际归还发生在使用日之后，按实际归还日期的日终延长历史占用；仍在使用且已经过使用日的设备在空闲候选中保持占用，直到归还。验货使 `shipped` 变为 `returned` 时也须写入该时刻。
- 现有“待归还”查询合并两种方式：`shipped` 现场主租赁在 `end_date <= 今天` 时进入列表，应归还日为使用日，今天显示待归还、明天起计算逾期天数；快递主租赁仍在 `end_date <= 昨天` 时进入列表，应归还日为结束日次日。PC / 移动端都提供现场单的“标记已归还”动作。

### 查询与履约隔离

- 档期冲突、空闲查询和每日空闲数共同使用占用边界，对两种履约方式都生效；现场与快递之间也能互相提示冲突。
- `find-slot` 按履约方式接收候选日期；快递沿用物流缓冲，现场按整个使用日查询，返回同仓同型号候选。表单切换方式或日期后清除旧候选和冲突结论。
- 所有快递候选查询、寄出统计、合包 / 预约 / 打印 / 追踪与后台发货任务按 `fulfillment_mode=courier` 过滤；单笔 API 再校验模式，拒绝误传现场租赁 ID。
- 甘特保留使用日租赁条，展示现场标识。现场单不贡献“今日寄出”数量；待归还数量和操作由现有待归还功能承载。

## Risks / Trade-offs

- 现有库存和甘特查询有仅凭 `ship_*` 非空判断占用的路径；实施时必须统一改为按履约方式计算，避免现场单被漏算。
- 现场单可以有闲鱼订单号而无运单，现有自动发货任务必须按履约方式过滤，否则可能错误通知闲鱼。
- 创建端当前允许跨订单占用重叠；现场场景保留该策略并用明显冲突提示，避免悄悄改变已有业务规则。
- 现场单只按整天判断冲突，不能安排同一设备一天内两段互不重叠的现场租赁；`onsite_returned_at` 仅用于真实归还记录和晚还时延长历史占用。

## Migration / Rollback

- 仅新增带默认值的租户业务库字段；不修改控制库及现有状态枚举。
- 部署前验证历史行全部为 `courier`，既有快递创建和发货行为不变。回滚应用时新字段可留在库中，旧代码忽略它；已经创建的现场单需避免由旧发货入口处理，故正式回退需先停用相应发货任务或补丁隔离。
