## ADDED Requirements

### Requirement: 现场租赁不得进入快递履约

快递日期候选、合包、预约顺丰、面单与发货单打印、快递追踪、闲鱼发货回传及后台定时发货 MUST 只处理 `courier` 租赁。服务端在任何按 ID 执行的快递动作前 MUST 复核履约方式；现场单即使处于 `not_shipped` 或有闲鱼订单号也不得创建运单、打印快递单、修改快递状态或调用外部发货接口。

#### Scenario: 批量预约夹带现场单
- **WHEN** 一批预约发货 ID 同时含快递单和现场单
- **THEN** 现场单返回明确失败且保持原状；有效快递单按当前逐包裹处理规则继续执行

#### Scenario: 直接调用单笔发货 API
- **WHEN** 客户端对现场单调用顺丰、快麦或闲鱼发货端点
- **THEN** 服务端拒绝，不产生外部请求，也不改变现场单状态或时间
