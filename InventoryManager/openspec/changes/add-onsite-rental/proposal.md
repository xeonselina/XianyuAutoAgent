# Change: 支持当天归还的现场租赁

## Why

设备送到使用现场、当天收回的租赁需要占用档期，但没有快递物流、收件地址，也可能没有闲鱼订单号。目前新建表单即使选择 0 天物流，也会在使用日前后各预留一天；发货和待归还入口又默认所有租赁走快递流程。

## What Changes

- 新增租赁履约方式 `courier`（现有快递）和 `onsite`（现场）；历史数据及旧客户端请求默认 `courier`。
- 现场单只选一个使用日期，新建时默认今天；主机及库存附件按这一天占用档期，不要求填写设备占用时刻，也不加物流缓冲。
- 现场单仅要求具体仓库、设备、客户称呼和使用日期；电话、现场地点备注、金额、闲鱼订单号均可选；不要求收件地址、运单号或闲鱼店铺。
- PC 和移动端的新建、编辑、甘特详情显示现场标识和合适的字段与状态文案；保留现有同型号多设备、库存附件、组合与金额规则。
- 现场单从批量发货、顺丰预约与面单、闲鱼发货、物流时效预估及寄出数量中排除。服务端也拒绝对现场单调用发货动作。
- 将已交付的现场单接入现有“待归还”功能：使用日当天显示应归还，次日仍未归还则显示逾期；支持从待归还列表标记已归还。

## Product Flow

1. 在甘特图选择“新建租赁”，履约方式选择“现场租赁”。
2. 使用日期预填今天，可修改；选择仓库、主机及附件，填写客户称呼；需要时补电话、现场地点备注、金额和闲鱼订单号。
3. 表单显示按天计算的冲突提醒；保存后甘特在使用日显示“现场”标识。
4. 交付设备时标记“已交付”，回收设备时核对并标记“已归还”；可继续使用现有验货流程。

## Boundaries

- 第一期一张现场单只占用一个使用日；跨日现场活动后续另议。晚还可发生在次日，系统自动记录实际归还时刻。
- 履约方式在创建表单里可切换；保存后不可改，以免已有运单、预约发货或同单多设备关联被重解释。
- 同一预约的多台主机必须采用同一履约方式；无闲鱼订单号仍可一次录入多台现场设备，但不能补进一张快递预约。
- 与现有建单规则一致，档期冲突显著提示，但不阻止有意保留的重叠预约；同一次预约内不能重复选择同一库存设备。
- `shipped` / `returned` 等数据库状态保持不变，现场界面分别显示“已交付 / 已归还”，避免改动现有状态枚举和验货契约。
- 现场单不保存 `ship_out_time` / `ship_in_time`；按使用日期整天判断档期占用，实际归还时刻单独记录。界面不出现“发货 / 物流”文案。
- 有闲鱼订单号的现场单仍可参与订单关联及退款提醒，但不会自动向闲鱼回传快递发货；无订单号不生成虚构单号或店铺。
- 不自动改写现有快递租赁，也不把地址、快递单号或 `scheduled_for_shipping` 状态迁移到现场单。

## Impact

- Affected specs: `onsite-rental`（新增）、`rental-management`、`gantt-scheduling`、`shipping-fulfillment`。
- Affected code: 租赁模型及租户库迁移、租赁创建 / 编辑 / 状态与查档期服务、甘特和每日统计、待归还、批量发货及相关 API、PC / 移动端新建和编辑表单。
- Existing proposals: `add-same-model-multi-device-booking`、`add-scheduled-shipping-status`、`simplify-batch-shipping-flow` 等与同单及发货入口相邻；实施时按当前代码和已合入行为核对。

## Review Decisions

- 现场单按使用日整天占用；不在表单里估计离仓和回仓时刻。
- 已交付但逾期未还时，设备在空闲查询中保持占用；待归还列表从使用日当天起显示该单，次日起显示逾期。
- 现场单的闲鱼订单号可选。有号时只做订单关联 / 对账，不执行快递发货回传。
- 归还时保留“已归还”与“已完成”两步，便于沿用现有验货；第一期不新增现场签收、押金或支付功能。
