## ADDED Requirements

### Requirement: 热敏内容联突出非默认租赁组合
每台设备的内容联 MUST 显示订单保存的组合名称；当组合不同于设备型号当前默认租赁组合时，MUST 在组合文字外绘制完整黑色矩形边框。默认组合保持普通文字，旧订单按保存的镜头枚举与型号默认镜头比较。缺少组合信息时不得误标；绘图必须保证长组合名称换行后仍完整落在边框内。打印和生成失败均不改订单数据，PC 和移动端调用相同输出。

#### Scenario: 非默认组合跨行
- **WHEN** 非默认组合名称超过热敏内容联单行宽度
- **THEN** 名称换行且每行文字都落在同一个完整黑框内

#### Scenario: 默认组合和旧订单
- **WHEN** 默认组合或旧订单默认镜头打印内容联
- **THEN** 组合名称显示但没有黑框；旧订单的非默认镜头则有黑框
