## Context

现有对账结果由 `/api/xianyu-order-alerts` 返回，PC 甘特图已实现提醒；手机端已有甘特图、新建租赁、租赁详情及仓库切换流程。

## Goals / Non-Goals

- Goals: 手机端看到并处理与 PC 相同的订单风险；复用服务端结果及手机现有业务流程。
- Non-Goals: 更改对账规则、自动删除档期、增加后端接口或迁移。

## Decisions

- 在手机甘特图内显示可展开提醒，保留甘特图可用空间；进入页面和操作后读取最新快照。
- 跳转至现有新建租赁页并通过路由参数传递订单号和店铺；现有订单详情查询填入客户信息，其他租赁字段仍由用户完成。
- 删除前重新读取租赁记录，核对店铺、订单号、状态及仓库，切换到对应仓库后复核，再展示明确的确认信息；已发货或仅需退款核对的档期进入现有编辑流程。
- 永久忽略操作先校验原因，再明确提示其不可恢复性；继续使用现有两种忽略接口。

## Risks / Trade-offs

- 提醒可能在操作期间变化：复核租赁身份、状态和仓库；不符合时停止操作并刷新提醒。
- 手机屏幕空间有限：提醒详情收起显示，展开区域限制高度并允许滚动。

## Migration Plan

无数据库迁移；手机前端构建后随现有静态资源发布。
