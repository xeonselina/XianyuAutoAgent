# 预定设备弹框独立选择设备型号

## 背景

桌面端甘特图的“预定设备”弹框目前依赖甘特图页面的设备型号筛选。“查找档期”会读取页面当前型号，用户无法在弹框内直接更换型号。

## 目标

在预定弹框内新增独立的设备型号选择，让用户无需退出弹框或调整甘特图筛选即可选择目标型号，同时保留甘特图当前型号作为便捷默认值。

## 交互设计

- 在开始、结束日期之后增加必选的“设备型号”下拉框。
- 每次打开弹框时，以甘特图当前筛选型号作为初始值。
- 用户在弹框内修改型号时，不改变甘特图页面的筛选条件。
- “选择设备”下拉框仅展示弹框所选型号对应的主设备。
- “查找档期”使用弹框所选型号的 ID 查询。
- 切换设备型号时，清空已选设备、已找到的档期及设备可用性结果，避免保留与新型号不匹配的状态。
- 未选择型号时，“查找档期”不可执行；若通过其他方式触发，则提示“请先选择设备型号”。
- 关闭弹框时清空弹框内型号状态；下次打开时重新读取甘特图的当前筛选型号。

## 数据流

`GanttChart` 继续通过 `selectedDeviceModel` 属性向 `BookingDialog` 提供甘特图当前型号的展示名，仅用于弹框打开时初始化。

`BookingDialog` 新增自己的型号 ID 状态。设备型号列表加载完成后，根据传入的展示名匹配型号并设置初始 ID。后续的设备过滤、镜头组合型号推导以及档期查询均读取弹框自身状态，不再持续依赖甘特图筛选。

当型号发生变化时，弹框根据设备的 `model_id` 筛选主设备。对于缺少 `model_id` 的兼容数据，可用设备关联型号的名称或设备原始 `model` 字段进行匹配，避免旧数据完全不可选。

## 错误与边界处理

- 甘特图未选择型号时，弹框型号保持为空，由用户选择。
- 甘特图型号在型号列表中无法匹配时，弹框型号保持为空。
- 型号切换后没有对应设备时，设备下拉框显示为空，用户仍可使用“查找档期”获得无库存提示。
- 已售出、损坏、停用或退役设备继续沿用现有禁用规则。
- 型号、日期变化或弹框关闭后，忽略此前尚未完成的查档与可用性检查结果，避免旧请求覆盖新状态。
- 日期、物流天数、附件和提交逻辑保持不变。

## 测试

新增 `BookingDialog` 组件测试，覆盖：

1. 打开弹框并加载型号后，默认选中甘特图传入的型号。
2. 弹框内切换型号不会修改父组件的甘特图筛选值。
3. 设备下拉框只渲染所选型号的设备，并保留生命周期禁用规则。
4. 切换型号会清空已选设备和旧档期状态。
5. “查找档期”传入弹框所选型号 ID，而非甘特图初始型号。
6. 未选择型号时不会发起档期查询，并显示明确提示。
7. 型号切换后，晚到的旧型号查档或可用性检查结果不会恢复旧设备状态。

## 非目标

- 不修改移动端新增预定页面。
- 不改变甘特图型号筛选行为。
- 不调整后端接口或数据库结构。
- 不重构现有预定表单的其他字段。
